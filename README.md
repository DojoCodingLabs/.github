# DojoCodingLabs/.github

Org-level defaults for [Dojo Coding](https://github.com/DojoCodingLabs).

- **[`profile/README.md`](profile/README.md)** — the organization profile README rendered at
  [github.com/DojoCodingLabs](https://github.com/DojoCodingLabs). This is the **only** path GitHub reads
  for the org page. Edit that file to change the org landing page.
- **`assets/`** — images referenced by the profile README. Reference them with absolute
  `https://raw.githubusercontent.com/DojoCodingLabs/.github/main/assets/...` URLs; relative paths do not
  resolve on the org profile page.
